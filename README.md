# CampusPulse.AI

CampusPulse.AI is an AI-powered campus assistant that helps students stay updated with college notices, announcements, deadlines, schedules, cancellations, and important campus updates.

## 🚧 Project Status

Currently under development.

## ✨ Features

* 📢 College notice and announcement tracking
* 📅 Deadline and important-date extraction
* 🔄 Detection of changes between old and new notices
* ⚠️ Identification of outdated or irrelevant notices
* 🤖 AI-powered notice understanding
* 💬 **Ask CampusPulse** — conversational assistant for campus-related queries
* 📝 Plain-language explanations of important notice changes

## 🧠 AI Capabilities

CampusPulse.AI is designed to understand college notices and extract useful information instead of simply displaying raw notice text.

The AI layer focuses on:

* Identifying important dates and their roles
* Distinguishing actual deadlines from other dates
* Detecting outdated or mismatched notices
* Comparing old and new notices
* Identifying meaningful changes such as:

  * deadlines
  * schedules
  * cancellations
  * locations
  * eligibility
  * fees
  * requirements
* Explaining important changes in simple language
* Answering student questions using available campus information

## 💬 Ask CampusPulse

The **Ask CampusPulse** assistant allows students to ask questions about campus notices and receive concise, context-aware answers.

Example questions:

> What is the deadline for this application?

> Did the exam schedule change?

> What changed between the old and new notice?

> Which documents are required?

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/shriya-kiran04/CampusPulse.AI.git
```

Navigate to the project directory:

```bash
cd CampusPulse.AI
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
